# SID Roadmap

SID means Systems Interface Director. She is designed as a desktop-first AI assistant that can grow from a polished prototype into a powerful work companion.

## Phase 1: Desktop Shell

- Electron app
- Animated SID interface
- Voice input and voice output
- Local memory notes
- Guarded desktop tools

## Phase 2: Real AI Brain

- Connect an LLM through a backend or Electron main process
- Add tool calling for files, apps, browser, calendar, and project actions
- Stream responses instead of waiting for full replies
- Add a strict permission policy for risky actions

## Phase 3: Work Automation

- File search and summarization
- Browser research with citations
- App launching and workflow shortcuts
- Reminders and task tracking
- Project-aware coding assistant mode

## Phase 4: FRIDAY-Style Experience

- Realtime voice conversation
- Screen vision and OCR
- Wake word
- Long-term memory
- Custom female voice
- 3D avatar or holographic interface

## Safety Rule

SID should never silently perform destructive actions. File deletion, payments, messages, emails, installs, and system changes must require clear user confirmation.
